# 1. Objetivo del proyecto

## Objetivo general

Construir una presencia digital moderna para Hygea que transmita profesionalismo, confianza y calidad, permitiendo que empresas, consorcios e instituciones conozcan la empresa y soliciten un presupuesto.

## Objetivos específicos

- Presentar la identidad de la empresa.
- Mostrar los servicios ofrecidos.
- Explicar la metodología de trabajo.
- Generar confianza mediante testimonios y trabajos realizados.
- Facilitar el contacto con potenciales clientes.

---

# 2. Público objetivo

La web está orientada principalmente a:

- Empresas
- Consorcios
- Constructoras
- Comercios
- Instituciones
- Administraciones

El visitante busca un proveedor confiable para contratar un servicio de limpieza y mantenimiento.

---

# 3. Identidad de marca

La web debe transmitir:

- Profesionalismo
- Confianza
- Organización
- Cercanía
- Calidad
- Compromiso

No buscamos una imagen llamativa o extravagante, sino una presencia corporativa sólida y moderna.

# 10. Filosofía del proyecto

Este proyecto tiene un doble objetivo.

Por un lado construir una web profesional para Hygea.

Por otro, utilizar el desarrollo del sitio como un proceso de aprendizaje de desarrollo frontend moderno con Astro, Git y buenas prácticas de arquitectura de software.
